# M1 — Initial Access

## Objective

Document the reconnaissance and validation steps that led to access to restricted functionality within the authorized Mediroza training environment.

## Assessment Activities

- Web reconnaissance
- Technology fingerprinting
- HTTP/header analysis
- Directory and resource enumeration
- `robots.txt` review
- Username enumeration
- Authentication/input-handling assessment
- SQL injection validation
- Restricted-area access validation

## Evidence Representation

The complete evidence package contains the original outputs and screenshots used during the assessment.

For this public repository, sensitive raw evidence is intentionally excluded.

## Key Security Lesson

Authentication and input-handling weaknesses can turn a seemingly restricted application area into an unauthorized access path. Validation should include both authentication logic and server-side input handling.
