# M2 — Data Extraction

## Objective

Assess the protection applied to three retrieved patient-report PDF files within the authorized training environment.

## Assessment Activities

- Identification of document protection
- Password/hash extraction
- Password recovery testing
- PDF decryption
- Validation of successful document access

## Evidence Representation

The private academic evidence package contains the original protected PDFs, recovered/decrypted copies, and supporting evidence.

Those files are intentionally **not published** in this public repository.

## Key Security Lesson

Password-protected documents can become accessible when an attacker obtains the file and the password protection is weak enough to permit recovery. Strong cryptographic protection and secure password management are essential for sensitive documents.
